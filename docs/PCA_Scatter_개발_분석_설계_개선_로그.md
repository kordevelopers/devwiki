# PCA 스캐터 차트 개발/분석/설계/개선 통합 문서

> 목적: PCA 스캐터 차트 기능의 요구사항, 분석, 설계, 구현, 개선 사항을 **단일 문서에서 지속 관리**한다.
> 운영 원칙: 기능 변경 시 이 문서를 계속 업데이트한다.

---

## 1) 요구사항 요약

- PCA 스캐터 차트 신규 화면 제공
- 샘플 데이터 랜덤 생성
- 시리즈 구분: `Fail`, `Pass`, `Insufficient`
- 포인트 클릭 시 하단 그리드에 선택 데이터 표시
- 차트 배경: 흰색 기반의 깔끔한 스타일
- X/Y 축 범위: 1~100
- 레전드(범례): 이동 불가(고정)

---

## 2) 분석 (Analysis)

### 2.1 기능 관점
- 현재 차트는 `LightningScatter` 래퍼를 통해 생성/옵션 적용/이벤트 처리 구조를 가짐.
- PCA 샘플 폼은 별도 Form으로 분리되어 기존 샘플 메뉴와 독립적으로 동작 가능.
- 데이터는 실제 PCA 계산 대신 시연용 분포 생성 방식(클러스터 중심 + 정규분포)으로 구현됨.

### 2.2 UI/UX 관점
- 사용자에게 중요한 시각 요소:
  - 배경/그리드/축/범례 색 대비
  - 군집 구분 색상 명확성
  - 클릭 후 상세 데이터 확인 동선
- 레전드가 이동되면 화면 일관성이 깨져 운영 화면에서 불리함.

### 2.3 기술 관점
- LightningChart 기본 테마 영향으로 배경이 어둡게 표시될 수 있음.
- 따라서 옵션뿐 아니라 차트 레벨 배경/테마/Fill 스타일 동시 제어 필요.
- 레전드 고정을 위해 `LegendBoxXY`의 mouse move/resize 속성 제어 필요.

## 3) 설계 (Design)

### 3.1 화면 구성
- 상단: 안내 문구 + 랜덤 재생성 버튼
- 중앙: PCA 스캐터 차트
- 하단: 선택 포인트 상세 그리드

### 3.2 데이터 설계
- `PcaSampleData`
  - SampleId
  - Category (Fail/Pass/Insufficient)
  - Pca1, Pca2
  - RawX, RawY
  - Score
- 랜덤 생성 후 PCA 점수는 1~100 범위로 클램프

### 3.3 시각 설계
- 차트/그래프 배경: white solid
- 축 범위: X=1~100, Y=1~100
- 범례 스타일:
  - 밝은 배경
  - 얇은 경계선
  - 저채도 텍스트
  - 이동/리사이즈 불가
